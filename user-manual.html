Application Overview

What MiniSpector Log does and the three-screen flow

MiniSpector Log is a digital reporting tool for ROV (Remotely Operated Vehicle) inspection teams. It replaces paper logs and spreadsheets with a structured, cloud-synced system used by both vessel crews and office teams.

Three-Screen Flow
Login Screen
→
Mode Select
→
Dashboard

Every session follows this path. After login you choose what to do; the dashboard is where all work happens.

Simulation Mode

Pre-mission planning. Build sensor lists, define topology, get approval — before the ROV goes in the water.

Operation Mode

Live mission logging at sea. Dive logs, shift records, maintenance, faults, HSE reports — all in one place.

Admin Setup (First Launch)

One-time setup before anyone else logs in

This section applies only to the very first person to open the admin panel on a fresh installation. Skip to Section 4 if an admin already exists.
How to Access the First-Time Setup
  1. Click "Admin" — bottom-right corner of the Login screen A small modal dialog opens. If no admin exists yet, it shows a yellow notice: "No admin account found. Create your credentials now."
  2. Fill in your chosen username and password The username can be anything (e.g. "admin" or your name). The password must be at least 1 character — choose something you can remember, as it cannot be recovered.
  3. Click "Create Admin Account"
    Create Admin Account
    A success message appears and the Admin Panel opens immediately.
There is only one admin account per installation. The admin login is completely separate from regular user IDs — regular users never see or use an admin password.

Modal Log Entry Pattern

Every log section (Dive, Fault, HSE, etc.) uses the same pattern:

  1. Click the "+ Add" button for that section. A dialog opens.
  2. Fill in the fields in the modal form.
  3. Click Save — the entry appears as a card in the list.
  4. To edit — click any existing card to reopen the modal with its data pre-filled.
  5. To delete — look for a trash icon inside the card or modal.

Push to Operation

Transferring all simulation data into the live operation session

Approved Simulation
→

→

What Gets Transferred Automatically
  • Project name, code, and scope
  • All mission sensors + calibration/test status
  • Machine/computer list with IP addresses
  • Equipment and hardware list
  • ROV unit roster (main/standby roles)
  • Thruster configuration & system IPs
How to Push
  1. Open the approved simulation — green "Approved" badge must be visible.
  2. Click "Push to Operation" in the simulation toolbar
    → Push to Operation
  3. A confirmation dialog appears — review what will be transferred and click "Proceed".
  4. The app switches to Operation mode — all data is pre-filled. A "Packing List & Equipment" tab appears in the sidebar.
After push, the simulation is locked — an orange "SIMULATION LOCKED" banner appears. Use "Unlock & Re-edit" only if changes are needed before a re-push. The operation data syncs to the cloud immediately so other team members joining by project code get the pre-filled operation.

Cloud Sync & Auto-Save

How your data is protected and shared

Auto-Save (every 3 min)

Runs silently in the background. Stores a local draft. The "Auto-saved" spinning indicator appears briefly. Protects against crashes and power loss.

Cloud Sync (manual)

Triggered by clicking the "Sync" button in the header, or automatically after every manual Save. Pushes data to the cloud so other devices see it.

Offline Queue

No internet? Saves go into a local queue. When the connection returns, all queued changes are flushed to the cloud automatically.

Cloud Polling (every 30s)

While a project is open, the app checks for cloud updates every 30 seconds. Approval status updates silently with a toast. Other data changes show a confirm dialog.

User Roles Reference

Who can do what

Role How to Get It What They Can Do Cannot Do
Admin First-time setup (one per install) Manage all users and project access. Not project-specific. Cannot log in as a regular user simultaneously
Operator Assigned by admin in Projects tab Full edit: all logs, checklists, save, sync, export. Submit simulation for approval. Cannot approve/reject simulations
Approver Assigned by admin in Projects tab Everything an Operator can do, plus: sees the Approvals sidebar tab and can approve or reject submitted simulations. —
Viewer Assigned by admin in Projects tab Browse all tabs and read all data. Sees the same view as the team. Cannot edit, save, submit, export, or sync.
Reviewer Enters via Review Access on login screen — no User ID needed Same read-only browsing as Viewer. Enters with just a project code. Cannot access Admin Panel, Approvals, or any write operation.

Quick Start Checklist

Ordered task list for each role on a new deployment

Admin — Do This First
  • Open app → click "Admin" (bottom-right corner)
  • Complete first-time admin account setup
  • Go to Users tab → add all team members (User ID + Name)
  • Share each person's User ID with them
  • After a project is created — go to Projects tab, enter code, and assign member roles
Simulation Lead
  • Log in with your User ID and PIN
  • Select "New Project" → "Start with Simulation"
  • Step 1: Fill ROV configuration and scope
  • Step 2: Complete Sensors & Equipment tab
  • Step 2: Complete Topology tab
  • Save — note the auto-generated project code
  • Tell admin to add team members to the project
  • Click "Submit for Approval" when ready
Approver
  • Log in with your User ID and PIN
  • Join the project by entering its code
  • Click "Approvals" in the sidebar (visible only to approvers)
  • Review the simulation data
  • Click Approve ✓ or Reject (with reason)
Vessel Crew (after push)
  • Log in with your User ID and PIN
  • Select "Join / Continue"
  • Enter the project code from the lead
  • Operation mode opens with all data pre-filled
  • Begin Mobilization checklist
  • Log shifts: Crew & Shifts → Add Shift
  • Log dives: Dive Log → + Add Dive
  • Report faults: Technical / Faults → + Add Fault
  • Manual sync after each major update
